# 工作文件 · 本地文件档案工具

一个纯前端的本地文件归档工具：归档、检索、查看、统计、备份，数据只存在浏览器里，不上传、不联网。

## 能做什么

- **归档**：拖入或拍照导入文件，按系列/文件夹归类，自动从文件名解析日期；导入 `.zip` 会自动解包成多条记录（压缩包本身不入库）
- **检索**：文件名、表格字段、Word/PDF/文本正文、图片 OCR 文字一起搜，命中后直接跳进文件定位
- **查看**：Word（docx）、Excel（xlsx/csv）、PDF、图片、纯文本内置预览；PDF 的文字可以选中复制；命中词高亮并放大，表格同步标出命中的行列表头
- **统计**：按系列出表格、导 CSV
- **备份**：整库导出 zip，换设备导入还原
- **同步**：同一 WiFi 下扫码连电脑，局域网点对点互传。先由手机回报差额，电脑端可勾选要发哪些文件；传完自动对账，缺的会重传，仍缺会把文件名列出来。文件多或单个文件很大时，改用「导出备份 → 手机端合并导入」更稳

## 跑起来

```bash
cd 工作文件
node server.js          # 默认 5173 端口
```

打开 `http://127.0.0.1:5173/`。也可以用任意静态服务器托管 `工作文件/` 目录，`server.js` 只是本地开发用的静态服务（带安全头与路径拦截）。

## 目录

```
工作文件/            应用本体（index.html + js + css + vendor + sw.js）
docs/               架构说明、恢复指南、现状 PRD
tests-workfile/     回归测试用的合成样例（不含真实资料）
VERSION.md          版本索引与存档说明
```

## 线上部署

push 到 `main` 后由 `.github/workflows/pages.yml` 自动发布 `工作文件/` 到 GitHub Pages，访问 `https://<用户名>.github.io/Dsearch/`。

`server.js` 在 Pages 上不参与运行，静态托管足够；只有局域网扫码同步需要本机启动它。

## 隐私与安全

- 应用数据存在使用者本机浏览器的 IndexedDB 里，仓库和线上页面都拿不到
- 仓库不含访问口令、账号、密钥、数据库连接，也不含个人工作文件
- 测试样例全部是合成的，正文为通用的中性内容（不含任何真实资料）
- 文档里的本机路径统一用 `~/Desktop/Dsearch` 占位
