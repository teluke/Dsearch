## 1. 产品定位

面向一线教师的**本地文件档案工具**：把散落在微信、相册、电脑里的材料收进一份按时间排列的台账，识别文件名里的日期与序号，把同系列文档的关键信息抽成表格，并支持按关键词检索（含图片里的文字）。全部数据留在当前设备，无账号、无云端、无第三方请求。

一句话：**文件进得来、日期说得清、序号理得顺、内容比得动、按词找得到、数据丢不了。**

### 目标用户与场景

| 场景 | 用户动作 | 结果 |
| --- | --- | --- |
| 日常归档 | 选文件/拍照 → 补字段 → 保存 | 十秒入库，时间轴立即出现 |
| 批量归档 | 多选一批文件 | 自动解析日期与序号，按系列归类 |
| 系列对照 | 打开统计页选系列 | 生成横向可比表格，可导出 CSV |
| 找文件 | 顶部搜索框输入关键词 | 文件名/字段/正文/图片文字全部参与 |
| 记待办 | 一句话快速添加 | 自动拆出时间、地点、事件类型 |
| 手机看资料 | 局域网扫码配对 | 电脑资料与待办实时到手机 |
| 换机兜底 | 导出 zip → 新设备导入 | 记录与文件本体完整还原 |

### 产品边界

- 单人、单设备、纯本地；不联网、不登录、无云同步服务端。
- 不做文档正文编辑，只做归档、提取与检索。
- 不做格式转换，文件以原格式保存。

## 3. 归档与系列

### 3.1 归档表单

- 入口：右下角 FAB（拍照/选文件）、归档页顶栏「导入」、主页空状态 CTA。
- 字段：文件名（可改）、文件日期、归档日期、**所属系列**、系列字段、备注。
- **所属系列**下拉末项为「＋ 新建系列…」：就地展开输入框，填名称回车/点新建即创建并自动选中，无需先去设置页。
- 单文件归档会先打开表单确认；多选批量归档直接入库（日期与序号自动解析），完成后提示「可点卡片补充字段」。

### 3.2 文件名解析

- **日期**：支持 `2026-11-20`、`20261120`、`2026年11月20日`、`11-20` 等；解析成功 `dateSource='name'`。
- **序号**：先剔除文件名中的日期片段，再识别 `第3次`、`第三次`、`第十二周`、`听课记录(2)`、`试卷-04`、`总结【5】`、末尾数字；存 `seq` + `seqTag`，列表显示徽标。

### 3.3 排序（全站统一）

1. 主日期新 → 旧；
2. 同一天、同主体文件：**序号大 → 小**；
3. 再按文件属性修改时间 **新 → 旧（同名新文件排前面）**；
4. `createdAt` 兜底。

### 3.4 系列模板

每个系列可定义字段（文本/数字/日期等），统计页按系列出表；系列可开启周期（周/月）形成周期事件。

## 4. 待办体系（主页核心）

### 4.1 一条待办的字段

`标题(text)`、`日期(date)`、`时间(time, HH:MM)`、`地点(place)`、`事件类型(kind)`、`完成(done)`。

### 4.2 一句话智能拆分

输入「下午3点 三楼会议室 教研组会议」→ 标题「教研组会议」／时间 15:00／地点 三楼会议室／事件类型「会议」。
支持：`HH:MM`、`N点`、`N点半`（含上午/下午/晚上前缀换算 24 小时制）；地点按常见后缀（会议室、教室、报告厅等）向前截取；事件类型自动归纳为 教研 / 听课 / 会议 / 培训 / 考试 / 作业 / 活动 / 材料。
拆不准时退回原文，绝不丢内容；也可用日期/时间/地点字段手填（手填优先）。

### 4.3 卡片呈现

- 标题 18px 加粗、最多两行；
- 下方一行三个彩色标签：**时间**（蓝）、**地点**（绿）、**事件**（橙）；无地点显示灰色「地点待定」；
- 右上角状态药丸：今天 / 明天 / N 天后 / 逾期 N 天 / 已完成；
- 操作按钮独立成行：完成勾选、推迟一天、修改、删除。

### 4.4 排序与筛选

- 全部待办（备忘录 + 周期事件）按事件时间排序：日期早 → 晚；同日按具体时间早 → 晚；无具体时间排在有时间的后面；周期事件用真实截止日期 `endISO` 参与排序。
- 本周日程（周一 → 周日）格子可点，带事项数角标；点某天 → 只显示当天待办（蓝色筛选条 + 「查看全部」），快速添加日期自动跟随所选日。

### 4.5 主页布局（v2.2.1）

删除时段问候语（早上好/晚上好等）与「暂无待办，一切就绪」文案；顶部只留一行「日期 · 共 N 份 · 已用 xx」，**待做事项紧随其后置顶**。

## 5. 检索与查看

### 5.1 检索范围

文件名、系列字段值、文档正文（docx/xlsx/pdf/txt/csv）、**图片 OCR 文字**统一参与；结果标注命中类型（全文 / 字段 / 图片文字）并给上下文摘要。

### 5.2 查看器

- 支持 docx（转 HTML）、xlsx/csv（表格）、pdf（逐页渲染）、图片、纯文本。
- 关键词定位：命中处高亮、`x/y` 计数、上一处/下一处跳转；PDF 定位到命中页。
- 宽表：**表头与序号列冻结**（左表头随横向滚动固定，上表头随纵向滚动固定）。
- 图片：下方显示「图片中的文字」面板（字数/置信度），可重试识别、单独清除。
- 底部控制栈：字体放大缩小、左右平移滑块、下载/外部打开。

## 6. 图片文字识别（OCR）

- 归档图片后自动在本机排队识别（可在设置关闭自动识别）。
- 引擎与语言模型全部打包在 `vendor/tesseract/`，**识别过程不联网、不上传**。
- 串行队列 + 进度提示；识别文本写入记录，参与全文检索与关键词表；刷新/重开自动续跑未完成任务。
- 设置页：自动识别开关、语言（中英混排 / 仅中文）、识别全部图片、清除全部识别文字。
- 说明：印刷体效果良好，手写体准确率有限；首次识别需加载约 6~8MB 模型，之后离线可用。

## 7. 手机端与多端

### 7.1 导入通道

手机端可从归档页顶栏、主页空状态、设置页三处导入文件或备份 zip；导入前显示摘要与容量校验。

### 7.2 局域网同步（电脑 → 手机）

- 同一 WiFi 下扫码配对，WebRTC 点对点直连，**不经服务器**。
- 电脑无相机时：可选二维码图片、粘贴截图（Ctrl+V）、手动粘贴返回码文本；整屏截图自动网格切片解码。手机端可保存返回码 PNG 或复制文本。
- 增量传输（按 `updatedAt`），16KB 分块；连接期间电脑端新增/修改/删除**文件与待办**，手机端 1~2 秒内自动刷新，主页统计数字同步更新。
- 单向推送（电脑 → 手机），避免双向冲突。

### 7.3 备份与恢复

导出 zip（`manifest.json` + `data.json` + `files/`），含记录、系列、待办、设置与文件本体；换机或清缓存前导出，新设备导入还原。
